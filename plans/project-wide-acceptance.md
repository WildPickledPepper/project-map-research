# MindStudio Insight 整体验收矩阵

日期：2026-10-25。状态：G01 通过，G02 执行中，其余门槛尚未执行；整体技术验收未通过。实施顺序见 [全项目实施计划](project-wide-completion-plan.md)。

本矩阵判断 Insight 全项目范围的完成情况。既有 P/A、skill 安装及功能回归继续作为各自范围的证据，不自动继承为下列门槛通过。

## 1. 判定对象和基本记录

每项结果绑定：产品源码提交、构建/部署配置、规则与依赖版本、模块与机制清单修订、输入数据、运行场景、参考版本、执行命令、实际输出和首次失败。

模块账本至少含逻辑 ID、源码范围、运行/公共库/构建/测试角色、语言、职责依据、入口/出口、边界、持有资源、适用模式、各门槛状态和证据。模块嵌套与共享依赖单独表达；结构目录不直接等于运行模块。

边界账本至少含消费/提供两端、方向、协议或交互机制、服务/实例域、接口身份、输入/输出、构建/运行条件、源码依据、解析结果、运行映射和验收 ID。来源位置清单与最终连接图分别保存。

机制账本为模块账本与 18 类机制的适用项展开。未使用某机制的判定需独立源码或构建依据；尚未实现、缺环境和分析超时均不是不适用。

**项目无关性属于 G01/G02/G07/G08 的必需检查。** 以至少两种不同布局的独立项目 fixture 和 Insight 检查同一引擎；改变项目名、模块名、任意目录布局及新增/改名/删除模块，不允许手改业务白名单或端点答案。账本由源码重新生成。出现未支持的新运行语言/机制时，必须自动登记缺口并保持相应整体门槛未通过；该检查不代表未知协议已被自动语义解析。

## 4. 最低负例和变更检查

| 组 | 检查 | 预期 |
|---|---|---|
| 身份隔离 | 同名函数位于不同包/命名空间；两个服务同命令/路径；不同数据库或实例同表/键 | 图中身份分离，确定边不误连，候选保留条件 |
| 异名连接 | 包别名、重导出、包装函数、端口/路径经参数或配置传递 | 从值来源连接，改名无需人工修改端点映射 |
| 动态目标 | 运行时端口、条件注册、Python 动态属性、Rust 宏/trait/闭包 | 静态状态、候选和所缺信息明确；适用运行场景补充实际目标 |
| 边界失效 | 删除提供方、移除注册、关闭 feature、改变进程参数或配置 | 原确定边退出或转为相应未匹配/有条件状态 |
| 跨文件失效 | 仅修改共享常量/配置/导出，消费者源码不变 | 消费者关联重新计算，不能沿用旧快照结论 |
| 对象/数据隔离 | 项目/设备切换、缓存键相同但所有者不同、按值复制与引用传递 | 数据及状态不会被无依据地跨对象传播 |
| 时序与异常 | 回调迟到、并发请求、取消/失败、退订/清理 | 关联身份正确，采用/丢弃/未完成分别记录，独立断言检查结果 |
| 采集完整性 | 缺中间阶段、重复身份、错连接、错构建/配置/数据 | 不接受为完整链，不直接叠加到当前上下文 |
| 故障有效性 | 对独立输入施加可控错误后恢复 | 预定义断言先失败再通过；不能改断言迎合输出 |
| 查询完整性 | 同名选择、分页、快照变化、预算耗尽和未映射事件 | 指明具体对象与快照；截断和剩余工作可继续查询 |

每个实际使用的边界家族至少有正常、身份/作用域负例和变更检查。机制 fixture 可复用，但不能替代其真实模块的连接核查。

## 5. 覆盖分母和未知项

分别报告以下指标，保留绝对数量与分母版本：

| 指标 | 分母和通过要求 |
|---|---|
| 文件归属 | 全部跟踪路径均有模块/角色/处理状态及依据 |
| 模块覆盖 | W0 所有自有运行模块；每项必须通过适用 G02–G08，整模块未提取为失败 |
| 语言覆盖 | 产品实际运行语言；各自真实模块、机制和更新验证通过，不能只以非零节点判定 |
| 边界处理 | 独立边界清单中的每个来源位置均有处理结果；明确静态身份应有正确连接 |
| 必需参考链 | W0 冻结的各模块/边界独立参考；全部必需事实、方向和条件正确 |
| 误连 | 在负例和独立源码核查范围内，任何已确认的确定错连均阻止相应门槛通过；核查范围同时公开 |
| 运行覆盖 | 每种必需模式、每个运行边界及适用关键状态分支有采集和独立断言；合并组合有等价依据 |
| 更新与查询 | 各语言/边界变更检查及全模块查询清单，均通过且无旧实体/关系残留 |

整体验收不使用一个加权总分掩盖空白模块。提取器输出本身不能作为全部召回率的分母；边界/调用解析率、独立参考召回率和实际运行覆盖分开。

具体动态未知可在以下条件同时满足时保留：已有可定位来源与条件，非整语言/模块/家族缺适配，独立参考确实不能静态唯一确定，查询没有给出过强结论，所需实际目标已由适用必需场景验证或有明确未覆盖标记。若该未知阻断必需参考链或核心场景，整体门槛仍未通过。

任何必需项改为不适用、合并运行组合、缩小分母、调整预期或升级工具，均记录旧/新值、源码/版本依据及影响检查。修复后的结果与首次结果并列保存。
