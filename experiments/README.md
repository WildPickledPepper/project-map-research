# 实验协议与下一轮任务

当前基准提交与案例来自 [unit/flows](../cases/unit-flows/README.md)。已有执行记录见 [2026-10-23 实测](../research/experiments/2026-10-23.md)。

## 每项实验固定记录

工具源地址与提交、执行发布版/二进制校验、许可证、操作系统与运行库、目标提交、过滤规则、索引模式、输入文件范围、命令、原始结果、耗时、主动中止条件、已验证与未验证项。

全仓和切片分开；原版与诊断补丁分开；不同边定义不按节点数排名；主动中止不写成自然失败；README 宣称不写成实测事实。

原始输出保存于 Git 忽略的 `artifacts/<run-id>/`。公开提交时仅放经过检查的摘要、小型脱敏证据和复现命令；第三方源码另行下载。

## 先做小范围验收

- 将请求、注册表、常量、分发和数据库接口/实现纳入真实源码切片，保留相对路径。
- 明确排除会被同名误匹配的负例，检查跨接口污染。
- 执行 S01–S07，保存实际图查询结果和源码核对。
- 在副本 fixture 上验证自动更新，并与同一最终状态的全量重建比较。
- 原版通过关键样例后，再扩到整个 Timeline 或全仓。

## 自动维护检查

至少覆盖：提供方删除、消费方删除、handler 重命名、常量值变化、module 相同 command 不同、command 相同 module 不同、目标类型变化、快速连续提交、失败重试和跨版本快照。

## 并行实验隔离

如启用独立智能体，各自固定输入、工具、配置、数据库和输出目录，不读取彼此结果，不互发候选链路或中间发现。主协调者最后对照基准汇总。

共享文件系统中的目录分离属于流程隔离，不宣称安全隔离。已有 2026-10-23 实验发生过隔离要求到达前的线索传递，因此不宣称严格盲测。
