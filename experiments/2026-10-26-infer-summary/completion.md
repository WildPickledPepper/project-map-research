日期：2026-10-26。范围：[计划 4.2](../../plans/semantic-impact-execution-plan.md)的 C++ 可组合候选；**采用 Infer 的原生效果摘要作为后续接入组件**。原生求解和跨函数组合均由上游完成，本项目读取 JSON、检查身份/条件及保留未知。

执行版本为 Infer `v1.3.0`，源码提交 `410a6d9394b9c9794bf9469ee0e1aa8d3ae91031`。首次 [run 40341615457](https://github.com/WildPickledPepper/project-map-research/actions/runs/40341615457) 与唯一复验 [run 40342344293](https://github.com/WildPickledPepper/project-map-research/actions/runs/40342344293) 的原始输出保存在 D 盘；[脱敏收据](evidence.json)保留命令范围、检查与成本。两个布局使用同一冻结源码，未修改期望或生产规则。

## 1. 已实测可复用什么

复用现成 `capture --headers`、`analyze --pulse-only` 以及 `debug --procedures --procedures-summary-json --dump-json-summaries`，两个编译单元的函数由 Infer 组合成调用方效果；可以直接取得参数/返回、前后堆关系、字段、路径条件、全局状态、写入位置与未知副作用。

| 固定检查 | 两种布局的结果 |
|---|---|
| 参数直接返回 | 返回与输入是同一原生值 |
| 跨文件 write→borrow→read | 调用方摘要保留输入到返回关系 |
| 字段写入、字段读取 | 分别保留参数→字段和字段→返回 |
| 引用返回 | 与原对象保持同一原生值 |
| 独立实例 | 返回值明确为 0，与被修改实例隔离 |
| 值复制后修改原对象 | 复验后返回值明确为 0，原生摘要无相关未知 |
| 全局写入→读取 | 调用方返回与输入是同一原生值，保留全局位置 |
| 条件选择对象 | 两个结果分别携带布尔参数等于 0 / 不等于 0 的对应分支条件 |
| 未解析函数指针 | 保留 `UnknownEffect`，不当成无副作用 |

每种布局 10 项能力检查通过，共 20 项。布局包含普通 `include/src` 和嵌套包目录。原生 JSON 各含 16 个过程，大小分别 68,583 / 70,467 字节。这是冻结小题的限定准入，真实 Insight 编译上下文、复杂模板、所有配置、递归以及与原有六项 SVF 题的通用值流等价仍待验证；通用 SVF 替代资格保持未通过。

## 2. 首次失败和复验依据

首次默认 capture 导出各 14 个过程，9/10 检查通过。`after_copy` 跳过头文件中的隐式构造，`unknown_values=true`，因此复制隔离检查失败。根据固定版本的[上游头文件选项](https://github.com/facebook/infer/blob/410a6d9394b9c9794bf9469ee0e1aa8d3ae91031/infer/src/base/Config.ml)，唯一复验添加 `--headers`，原 fixture 不变；构造函数进入原生分析后，该项通过。

另一个接口要求是同时检查原生状态与副作用标记：函数指针场景的 `unknown_values=false`，但对象属性含 `UnknownEffect`。接入时必须保留这些标记、skipped calls、opaque 字段和原生精度，不能仅凭一个布尔字段判断结果完备。

## 3. 成本和后续接入

复验每个布局 capture/analyze/export 的外部墙钟合计约 1.35 / 1.14 秒，最高采样进程树 RSS 为 526,594,048 / 401,326,080 字节。采样间隔 0.1 秒，小题短阶段存在漏峰可能，数值是已观测值；下载 275,901,768 字节二进制与安装等待单列。当前没有真实项目的建图成本测量，也没有同精度 SVF/Infer 大程序对照，不能将小题成本外推为原 13 GiB 问题已经解决。

下一步复用上游摘要作为 R3 效果输入：作用域至少包含版本、配置、过程原生身份、摘要分支、pre/post；字段/堆关系与通用值流分开，条件和未知随结果返回。函数来源及与编译器符号的连接需要保留精确证据。摘要缓存和循环依赖组合继续交给原生引擎。

本次没有安装第二个候选、读取 OCaml 二进制格式或自写数据流求解器。Rust 配置补图与全模块验收单独推进；R0/R1 总状态继续为 partial。
